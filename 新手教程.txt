启动
  下载 Releases 里的 DanmakuSender.exe 双击即可（窗口标题：弹幕补档机 RS）
  项目主页：https://github.com/iallemege/danmaku_RS-project （只在这里发版，不会发到 TouhouGleaners 组织）
  或源码：
    pip install -r requirements.txt
    python danmaku_sender.py

账号
  优先用「账号」页的「扫码登录」：用哔哩哔哩 App 扫窗口里的官方二维码
  也可以从浏览器复制 SESSDATA / bili_jct / buvid3，或把整段 Cookie 贴进去「检测并保存」
  「群发」列勾选后，该账号会进入发射页的同时发送队列
  Windows 下 Cookie 会用系统 DPAPI 加密存放，不要把 ~/.danmaku_rs/ 拷给别人

发射
  输入 BV 或视频链接（支持 ?p=）→ 获取分P
  打开本地 XML / JSONL，或「抓取线上弹幕」，或从「记忆馆」拉取馆藏 XML
  获取分 P 和抓取线上弹幕可以先不登录
  先勾选模拟模式，确认后再真实发送
  「本地预览弹幕」会在本机开一个预览页，不会发到 B 站
  「一键批量修复」会去换行并截断超长；校验器也可单独点「去换行」「截断超长」
  可开拟人间隔、爆发模式、时间轴平移、断点续传、最长运行分钟
  多账号同时发送：在「账号」页保存多个 Cookie，发射页勾选「多账号同时发送」并勾上要参与的账号
  队列按条数轮询均分，指纹全局去重，单个账号被限流或致命错误时只停该账号
  失败条目会单独导出；也可从「历史」载入失败 / 丢失后重发

记忆馆 / 失效稿
  「同步记忆馆」读取公开 videos.json（只读），按标题 / 标签 / UP 加权排序
  原视频已失效时：填 BV 或旧标题，点「失效稿跨站检索」
  会检查 B 站稿件状态，并搜索 B 站补档、Internet Archive、YouTube，同时给出 AcFun / niconico 等检索页
  「导入到发射器」或「拉取馆藏 XML」只从只读弹幕库取文件，不会把本工具发到 TouhouGleaners

设置
  代理策略：自动探测（系统代理或环境变量）/ 直连 / 系统 / 自定义
  点「探测当前代理」确认能否访问 B 站

其它页
  编辑器：全体/选中平移、删除、去重、排序、标记发送、导出 XML/JSONL，Ctrl+Z 撤销
  校验器：先扫描，再去换行 / 截断 / 一键修复，可撤销
  分割器：按条数、按时长、按署名均分
  监视巡检：开始实时监视后按间隔拉取登录态、线上覆盖率、发送成败，并自动核销待验证
  告警会按情况分级（登录失效 / 412 / 致命码 / 频率限制 / 失败率 / 覆盖率下降）
  历史：按内容 / BV / 状态查询，双击看档案，载入失败/丢失重发
