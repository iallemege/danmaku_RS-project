1. 获取账号 Cookies
   - 浏览器登录 B 站网页版
   - 按 F12 打开开发者工具
   - Application > Cookies
   - 复制 SESSDATA、bili_jct、buvid3
   - 也可以把整段 Cookie 直接粘贴到 SESSDATA 输入框

2. 安装运行环境
   - Python 3.8+
   - pip install -r requirements.txt

3. 启动
   python danmaku_restorer.py

4. 操作
   ① 粘贴凭证，点「检测登录」
   ② 输入目标 BV 号，点「获取分P」
   ③ 选择要补档的分P
   ④ 选择弹幕 XML
   ⑤ 先用「模拟模式」确认预览
   ⑥ 取消模拟后再点「开始补档」

参数
- 发送间隔默认 8 秒（可在 5–90 秒调整）
- 单次默认最多 200 条
- 断点续传按弹幕内容和时间指纹跳过已发送条目

注意
- 只能补你有权发送弹幕的稿件
- 遇到 36703 / 412 请加大间隔
- 遇到 36715 表示当日额度用尽
- 不要把 Cookie 提交到公开仓库
